# Archive Downloader

This repository provides a CLI for listing, configuring, and downloading files from archive.org item pages.

- Entry point: `archive_downloader.py`
- Full CLI reference and usage examples: `.claude/commands/archive_downloader.md`
- Use the `/archive_downloader` skill when helping the user run or debug this tool.

## Environment

- Install Python dependencies: `pip install -r requirements.txt`
- `curl` must be on `PATH` (required for `config` and `download` commands)
